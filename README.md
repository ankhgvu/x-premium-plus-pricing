## 国内付款卡在哪，怎么解决

官方结账目前主要收境外 Visa / Mastercard。国内银行卡、支付宝、微信基本进不去官方支付流程；部分虚拟卡卡段会被直接拒掉；网络 IP 环境也会触发风控。

绑卡前把这几样备齐：

1. 一张能国际支付的 Visa 或 Mastercard（实体、虚拟卡都可以试），余额略高于应付金额，给税费和汇率浮动留点空间。
2. 持卡人姓名填英文，账单地址按发卡平台要求的地区填英文地址。
3. 网络环境稳定，和账号常用地区保持一致，别一会儿一个 IP。

绑卡被拒时按这个顺序排查：

- 余额是否够扣（记得算上税）；
- 卡段是否被 X 订阅拒收——部分虚拟卡段就是过不了；
- 网络 IP 是否稳定、是否与账号常用地区冲突；
- 账单地址是否与发卡信息一致；
- 换浏览器、清缓存再试。

还有一个容易忽略的前提：所有订阅用户在开通时都必须确认手机号。同一个手机号绑过超过 10 个账号、绑在 30 天内删除的账号上、或绑在被封禁的账号上，都可能注册失败。

## 蓝标什么时候出现？什么情况会掉？

付费成功不等于秒出蓝标。订阅生效后账号会自动进入资格审核，通常要几个工作日；长帖、编辑帖子、Grok 额度这些功能先可用，蓝标后到。审核的基本要求：有显示名、有头像、已确认手机号。

三个动作会让蓝标暂时消失：改头像、改显示名、改 @用户名。改完需要重新过审，审核期间不能再改资料。所以开完会员先别急着装修主页。

还有个细节：广告减少的权益也要等蓝标过审后才生效。Premium 的“信息流广告减半”和 Premium+ 的“无广告”都是。
